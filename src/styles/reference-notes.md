# Línea visual v0.3 · Academic Workspace

Síntesis aplicada a partir de las referencias visuales suministradas para el repositorio del curso.

- Estructura de aplicación compacta: navegación lateral persistente + área central de trabajo + rail contextual opcional.
- Interfaz contenida, no landing page: menos altura de hero y más información útil visible sin scroll.
- Tarjetas de radio amplio (18–24 px), superficies blancas y acentos pastel muy contenidos.
- Paleta propia del curso: petróleo/teal profundo, marfil, aqua grisáceo y arena; se evita copiar la paleta violeta de las referencias.
- Tipografía sans predominante para interfaz; serif editorial solo como acento en títulos de curso y citas.
- Jerarquía compacta: títulos de página entre 32–48 px, etiquetas pequeñas en mayúsculas, metadatos densos y claros.
- Layout asimétrico: contenido principal 2/3 y columna contextual 1/3 en escritorio.
- Estados y acciones como pills/badges; botones pequeños y consistentes.
- Sombras muy suaves, bordes finos y fondos ligeramente diferenciados para dar profundidad sin apariencia de LMS corporativo.
- Responsive: sidebar se transforma en navegación horizontal desplazable y el rail contextual baja bajo el contenido.

Nombre del estilo: **Academic Workspace**.
