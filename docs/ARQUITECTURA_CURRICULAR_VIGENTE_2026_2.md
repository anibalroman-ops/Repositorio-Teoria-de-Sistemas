# Arquitectura curricular vigente — Teoría de Sistemas 2026-2

## Función de este documento

Este archivo registra las decisiones curriculares que el repositorio web debe tratar como vigentes. Su propósito es evitar que una página aislada mantenga versiones anteriores del curso.

## Jerarquía de fuentes académicas

1. **Programa oficial de asignatura**  
   Mantiene el Resultado de Aprendizaje general, las unidades oficiales y la identidad disciplinar de Teoría de Sistemas.

2. **Diseño clase a clase v0.3 — Equipo único**  
   Es la referencia operativa para calendario, secuencia de conocimientos, herramientas, hitos y productos del semestre.

3. **Documento Técnico Maestro BEAR v0.4**  
   Es la referencia para arquitectura de evidencia, Construct Maps y separación entre desempeño colectivo e inferencia individual.

4. **E3 Aplicación v0.7 y sus instrumentos**  
   Es la referencia vigente para E3 hasta que una versión posterior la reemplace explícitamente.

5. **Material final de cada sesión**  
   Cuando una clase dispone de una versión final posterior al diseño clase a clase, esa versión regula la implementación de esa sesión sin modificar por sí sola la arquitectura global del curso.

## Decisiones vigentes de implementación

### Cohorte y Proyecto Peñaflor

- Cohorte 2026-2: **5 estudiantes**.
- Proyecto Peñaflor: **1 equipo permanente**.
- Producto longitudinal: **1 construcción integrada con versiones sucesivas**.
- Pueden existir configuraciones didácticas temporales individuales, en parejas, 2+2+1 o 3+2.
- Los frentes A/B/C son **lentes o frentes analíticos**, no equipos.
- Las responsabilidades son rotativas.
- Todos los estudiantes deben comprender y poder defender el modelo completo.

### Principio de trabajo

**divergencia → contraste → consecuencias → convergencia → decisión justificada → registro**

### Secuencia del desafío real

**escuchar → representar la situación → comprender EHL/PACCC → proponer sistemas pertinentes → contrastar con Municipalidad → modelar implementación → diagnosticar brechas → diseñar hoja de ruta → defender profesionalmente**

### Frontera entre mandato municipal y construcción sistémica

La Municipalidad entrega un desafío profesional: articular EHL y PACCC en una hoja de ruta implementable.

Ese mandato **no equivale** a una situación-problema ya definida. La situación-problema, el sistema pertinente, sus límites y las intervenciones deben construirse y justificarse a partir de evidencia, perspectivas y contraste.
